# netsec-codemap

Static, interactive architecture map of the [netsec.github.io](https://github.com/EISSeuropa/netsec.github.io) codebase, generated with the Understand-Anything knowledge-graph tool.

Snapshot, not live: rebuilt by hand when the maintainer decides it is worth refreshing. See the `meta.json` for the analysed commit and date.

Live view: https://eisseuropa.github.io/netsec-codemap/
